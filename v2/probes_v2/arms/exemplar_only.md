介面文字的寫法：先決定這條字串是哪一種元件，再用那種元件的形式寫。每條字串只有一個工作。

| 元件 | 形式 | 範例 |
| --- | --- | --- |
| 按鈕 | 動作的名字，動詞開頭，沒有句號 | 取消、儲存、刪除、重新開機、稍後提醒、允許、不允許 |
| 對話框標題 | 這個決定或動作的名稱 | 刪除這筆紀錄、轉帳確認、中斷安裝 |
| 對話框說明 | 只寫讀者做決定需要、畫面上還沒有的後果 | 這筆紀錄與它的照片會一併刪除。／轉帳送出後無法取消。 |
| 狀態 | 已完成或進行中的狀態，句型「已＋動詞」「動詞＋完成」「動詞＋中」 | 已儲存、安裝完成、同步中、匯出中 42% |
| 錯誤 | 發生什麼、原因、下一步，各一句 | 無法安裝：這是目前的開機磁碟。請選擇其他磁碟。 |
| 空狀態 | 名詞或狀態；動作留給畫面上已有的按鈕 | 沒有紀錄、購物車是空的 |
| 標籤 | 名詞；無障礙標籤寫這個控制項做的事 | 熱量、關閉、搜尋、更多選項 |
| 數值 | 數字與單位；範圍放在數字後的括號裡 | 200 g（170–230 g）、128 / 2,400 mg、$4,812.00（−$96.20，−1.96%） |
| 小字備註 | 一句會改變旁邊數字或清單怎麼讀的事實；沒有就留空 | 醬汁另計／約 40 秒錄音聽不清楚／（空） |
| 標題 | 畫面或步驟的名稱 | 照片估算、連結銀行帳戶 |

同一個動作在整個 app 用同一個名字。台灣用語：目前、預設、設定、資料、影片、使用者、快取、軟體、網路、訊息。全形標點：，。：（）；範圍用「–」。

English: button = the action's name (Cancel, Save, Delete, Uninstall, Keep); status = the state (Saved, Export complete, Removing files…); error = what happened, cause, next step (Can't save settings: no connection to the server. Try again later.); value = figure with unit and range (38 USD est. (30–45)); note = one fact that changes the reading, or empty.

日本語：ボタン＝動作名（キャンセル、保存、削除、許可しない）；状態＝状態名（保存しました、通知をオフにしました、書き出し中 42%）；エラー＝何が起きたか・原因・次にできること（設定を保存できません。サーバーに接続できません。しばらくしてからもう一度お試しください。）；空の状態＝状態名（カートは空です）；備考＝数値の読み方を変える一文だけ、なければ空。
